# Code_Alpha_task2
A desktop GUI Chatbot built with Python and Tkinter featuring rule-based response logic and auto-closing on exit commands.
A lightweight desktop chatbot application with a clean Graphical User Interface (GUI) built using Python's native tkinter library.

The application processes user inputs using conditional matching logic and displays conversational responses inside a scrollable chat area.

✨ Key Features
Desktop GUI Interface: Styled interface using tkinter and scrolledtext widgets.

Rule-Based Response Engine: Pattern-matching logic for keywords (hello, how are you, bye, etc.).

Keyboard Shortcuts: Supports both direct Send button clicks and pressing the Enter key to send messages.

Auto-Scroll Chat Log: Automatically scrolls down as new messages are sent and received.

Graceful Exit: Automatically delays and closes the application when the user says "bye" or "exit".

🛠️ Tech Stack & Requirements
Language: Python 3.x

GUI Framework: tkinter (Included in standard Python installation)

Dependencies: None (Uses Python Standard Library only)
